## Formats Vidéo E-Commerce

### 1. UGC (User Generated Content) — le + performant
Vidéo style "personne réelle" filmée sur téléphone, paraît authentique
- Durée : 15-60 secondes
- Style : naturel, pas trop produit, caméra tenu à la main
- Idéal pour : produits lifestyle, beauté, fitness, maison

### 2. Démonstration Produit
Montre le produit en action, les résultats concrets
- Durée : 15-45 secondes
- Style : propre, éclairage studio ou naturel
- Idéal pour : gadgets, outils, produits techniques

### 3. Avant/Après
Transformation visible = puissant levier émotionnel
- Durée : 10-30 secondes
- Style : côte à côte ou transition
- Idéal pour : beauté, fitness, nettoyage, décoration

### 4. Témoignage Client
Un vrai client raconte son expérience
- Durée : 30-90 secondes
- Style : authentique, légèrement scripté
- Idéal pour : produits à résultat, suppléments, coaching

---

## Structure d'un Script Vidéo Gagnant

```
[0-3s]  HOOK — Arrête le scroll
[3-8s]  PROBLÈME — Empathie avec l'audience
[8-20s] SOLUTION — Présentation produit + démonstration
[20-30s] PREUVE — Résultat, témoignage, chiffre
[30-35s] CTA — Appel à l'action clair
```

## Templates de Scripts

### Template UGC — Style "Discovery"
```
[HOOK 0-3s]
"Sérieusement, pourquoi personne m'a parlé de ça avant ?"
[Montrer le produit à la caméra]

[PROBLÈME 3-8s]
"Ça fait [X mois/ans] que je galère avec [PROBLÈME].
J'ai tout essayé : [ALTERNATIVE 1], [ALTERNATIVE 2]...
Rien ne marchait vraiment."

[SOLUTION 8-20s]
"Et là une amie m'a conseillé [PRODUIT].
[Démonstration d'utilisation en 2-3 plans]
Le truc c'est que [MÉCANISME / ce qui le rend différent]"

[RÉSULTAT 20-30s]
"Après [TEMPS], [RÉSULTAT CONCRET].
Franchement je ne m'attendais pas à ça aussi vite."
[Montrer le résultat ou réaction authentique]

[CTA 30-35s]
"Le lien est dans la bio, ils livrent en [X] jours.
Je vous jure vous allez pas regretter."
```

### Template UGC — Style "Problem Reaction"
```
[HOOK 0-3s]
"POV : tu découvres [PRODUIT] pour la première fois"
[Réaction surprise/enthousiaste]

[PROBLÈME 3-8s]
"J'avais [PROBLÈME] depuis trop longtemps
et franchement ça commençait à me [IMPACT ÉMOTIONNEL]"

[SOLUTION 8-20s]
"[PRODUIT] c'est différent parce que [BÉNÉFICE UNIQUE]
Concrètement : [ÉTAPE 1], [ÉTAPE 2], [RÉSULTAT]"

[PREUVE 20-30s]
"[X] personnes l'utilisent déjà — et honnêtement les avis..."
[Montrer screenshot d'avis ou téléphone avec reviews]

[CTA 30-35s]
"Lien en bio — ils ont souvent des promos alors vérifiez"
```

### Template Démonstration Produit
```
[HOOK 0-3s]
"Regarde ce que ça fait..."
[Plan produit insolite ou surprising]

[DÉMO 3-25s]
Plan 1 : Déballage / présentation produit (3s)
Plan 2 : Utilisation - étape 1 (5s)
Plan 3 : Utilisation - étape 2 (5s)
Plan 4 : Résultat intermédiaire (5s)
Plan 5 : Résultat final impressionnant (7s)

[BÉNÉFICES 25-30s]
Text overlay : "✓ [BÉNÉFICE 1]"
Text overlay : "✓ [BÉNÉFICE 2]"
Text overlay : "✓ [BÉNÉFICE 3]"

[CTA 30-35s]
"Disponible maintenant — lien en bio"
```

## Brief pour UGC Creators

### Ce qu'il faut fournir au créateur :
```
BRIEF CRÉATEUR — [PRODUIT]
══════════════════════════

PRODUIT : [NOM] — [DESCRIPTION EN 1 PHRASE]
LIEN : [URL boutique]

CE QUE TU REÇOIS :
Le produit t'est envoyé gratuitement.
Rémunération : [X€] pour 1 vidéo livrée / usage illimité 6 mois

FORMAT :
- Durée : 30-45 secondes
- Format : vertical 9:16 (TikTok/Reels)
- Qualité : téléphone suffisant, bonne luminosité
- Son : parler clairement, pas de bruit de fond

ANGLE DEMANDÉ :
[CHOISIR : Discovery / Problem-Reaction / Before-After / Review]

POINTS À COUVRIR :
1. [POINT 1]
2. [POINT 2]
3. [POINT 3]

CE QU'ON NE VEUT PAS :
- Script robotique / trop "pub"
- Plans trop produits / éclairage studio
- Mentionner la concurrence

LIVRAISON :
- Fichier MP4 brut (sans sous-titres, sans musique)
- Date limite : [DATE]
- Envoyer via [WeTransfer / Google Drive / email]
```

## Hooks Vidéo — Banque de 30+

### Catégorie Pain Point
- "Si tu souffres de [PROBLÈME], cette vidéo est pour toi"
- "Pourquoi ta routine [DOMAINE] ne fonctionne pas (et comment y remédier)"
- "[X] signes que tu as besoin de [PRODUIT]"

### Catégorie Curiosité
- "Ce produit a changé ma façon de [ACTION]"
- "Le truc que les [AUDIENCE] utilisent et dont personne ne parle"
- "J'aurais aimé connaître ça il y a [X] ans"

### Catégorie Résultat
- "Comment j'ai [RÉSULTAT] en seulement [TEMPS]"
- "[AVANT] → [APRÈS] : mon expérience honnête"
- "[X] jours d'utilisation — voilà ce qui s'est passé"

### Catégorie Social Proof
- "[X] personnes l'utilisent déjà et voilà pourquoi"
- "Les avis sur ce produit m'ont convaincu(e) d'essayer"
- "J'étais sceptique... jusqu'à ce que [RÉSULTAT]"

### Catégorie Urgence/FOMO
- "Ça part vite — voilà pourquoi tout le monde en commande"
- "J'aurais regretté de rater ça"
- "Dépêche-toi avant [RAISON D'URGENCE]"
