## Concurrent #1 — Zooplus.fr

| Champ | Détail |
|-------|--------|
| **URL** | zooplus.fr |
| **Type** | Marketplace / e-commerce généraliste |
| **Produit phare** | Arbres à chat Zolia, Feliway |
| **Prix** | 15€ — 250€ (large gamme) |
| **Proposition de valeur** | "Tout pour les animaux, livraison rapide" |
| **Canaux d'acquisition** | SEO, Google Shopping, Email, Affiliation |
| **Points forts** | Notoriété, catalogue immense, livraison J+1 |
| **Points faibles** | Aucune émotion, pas de branding lifestyle, UX froide |
| **Opportunité pour nous** | Positionner une marque avec identité et storytelling vs le côté "supermarché en ligne" de Zooplus |

**Créatifs ads :** Visuels produits blancs, pas de lifestyle. Aucun contenu UGC.

## Opportunités Identifiées

1. **TikTok organique** — Aucun concurrent majeur n'a de stratégie TikTok sérieuse dans la niche
2. **Meta Ads lifestyle** — Peu d'ads avec contenu UGC/lifestyle de qualité
3. **Branding francophone** — Pas de marque DTC française avec identité forte
4. **Prix intermédiaire** — Gap entre les dropshippers bas de gamme et les marques premium
5. **SAV humain** — Se différencier avec un support client réel en français
