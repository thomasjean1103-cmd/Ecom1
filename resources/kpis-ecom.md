# KPIs E-Commerce — Métriques Clés & Formules

## KPIs Boutique

### Taux de Conversion (CVR)
```
Formule : Commandes / Sessions × 100
Exemple : 20 commandes / 1000 sessions = 2%
Cible   : >2% (bon), >3% (excellent)
Si <1%  : Problème page produit, prix ou offre
```

### Panier Moyen (AOV — Average Order Value)
```
Formule : Chiffre d'Affaires / Nombre de Commandes
Exemple : 4500€ / 100 commandes = 45€
Cible   : Dépend de la niche (viser 40-80€ idéalement)
```

### Taux d'Abandon de Panier
```
Formule : (Paniers créés - Achats) / Paniers créés × 100
Exemple : (150 - 100) / 150 = 33%
Cible   : <65% (la moyenne industrie est ~70%)
Si >75% : Problème au checkout (frais cachés, manque de paiement)
```

### Taux de Retour
```
Formule : Retours / Commandes × 100
Exemple : 5 retours / 100 commandes = 5%
Cible   : <5%
Si >10% : Problème qualité ou mauvaise description produit
```

## KPIs Publicité

### CPM (Coût Pour Mille Impressions)
```
Formule : Spend / Impressions × 1000
Exemple : 50€ / 5000 imp = 10€ CPM
Cible Meta   : <25€
Cible TikTok : <15€
Si élevé     : Audience trop petite ou saisonnalité
```

### CTR (Click-Through Rate)
```
Formule : Clics / Impressions × 100
Exemple : 100 clics / 5000 imp = 2%
Cible   : >1.5% (Meta), >1% (TikTok)
Si <0.8% : Changer le créatif immédiatement
```

### CPC (Coût Par Clic)
```
Formule : Spend / Clics
Exemple : 50€ / 100 clics = 0.50€ CPC
Cible   : <1€
Si >2€  : Créatif peu engageant ou audience trop chère
```

### CAC (Coût d'Acquisition Client)
```
Formule : Spend Total / Nombre de Clients Acquis
Exemple : 500€ / 20 clients = 25€ CAC
Cible   : <30-35% du prix de vente
Si trop élevé : Améliorer créatif, page produit ou offre
```

### ROAS (Return On Ad Spend)
```
Formule : Revenus Pub / Spend Pub
Exemple : 1500€ revenus / 500€ spend = 3x ROAS
Cible   : >2.5x (rentable), >3x (bon), >5x (excellent)
Break-even ROAS = 1 / Marge Brute
  Exemple : marge 40% → break-even = 2.5x
```

### MER (Marketing Efficiency Ratio)
```
Formule : CA Total / Spend Pub Total
Exemple : 5000€ CA / 1500€ spend = 3.3x MER
Note    : Plus fiable que ROAS car inclut tout le CA
Cible   : >3x
```

### ROAS Break-Even
```
Formule : 1 / Marge Brute (en décimal)
Exemple : Marge 35% → 1 / 0.35 = 2.86x ROAS minimum
```

## KPIs Financiers

### Marge Brute
```
Formule : (Prix Vente - Coût Produit) / Prix Vente × 100
Exemple : (45€ - 15€) / 45€ = 66.7%
Cible   : >50%
```

### Marge Nette
```
Formule : (CA - Toutes Dépenses) / CA × 100
Dépenses = Coût produit + Pub + Apps + Shopify + Livraison
Exemple  : (5000€ - 4000€) / 5000€ = 20%
Cible    : >15%
```

### LTV (Lifetime Value)
```
Formule  : AOV × Fréquence Achats/An × Durée Relation (ans)
Exemple  : 45€ × 2.5 × 2 = 225€ LTV
Cible    : LTV > 3× CAC
```

### Ratio LTV/CAC
```
Formule : LTV / CAC
Exemple : 225€ LTV / 30€ CAC = 7.5x
Cible   : >3x (sain), >5x (excellent)
Si <2x  : Business non viable à long terme
```

### Point de Break-Even Mensuel
```
Formule : Coûts Fixes / Marge Brute
Exemple : 500€ frais fixes / 60% marge = 833€ CA minimum
```

## KPIs Email

### Taux d'Ouverture
```
Cible : >25%
Bon   : >35%
Si <20% : Améliorer les objets, nettoyer la liste
```

### CTR Email
```
Formule : Clics / Emails Livrés × 100
Cible   : >2%
Si <1%  : Améliorer le contenu ou l'offre
```

### Revenue Per Email (RPE)
```
Formule : CA généré par l'email / Emails livrés
Cible   : >0.10€ par email
```

### Contribution Email au CA
```
Cible   : 20-30% du CA total
Si <10% : Développer les flows et newsletters
```
