# Checklist Lancement E-Commerce — Du Zéro à la Première Vente

## Phase 1 — Fondations (Semaine 1-2)

### Recherche & Validation
- [ ] Niche choisie et validée (agent-niche)
- [ ] Produit(s) sélectionné(s) avec marge >30% (agent-produit)
- [ ] Au moins 3 fournisseurs comparés
- [ ] Échantillon(s) commandé(s) et testés
- [ ] Concurrents analysés (5 minimum)
- [ ] Positionnement différenciant défini

### Marque
- [ ] Nom de marque choisi
- [ ] Domaine .com acheté (Namecheap ~12€/an)
- [ ] Logo créé (Looka, Canva ou Fiverr)
- [ ] Charte couleurs définie (primaire + secondaire + accent)
- [ ] Typographie choisie
- [ ] Brand DNA écrit (agent-branding)

---

## Phase 2 — Boutique (Semaine 2-3)

### Shopify Setup
- [ ] Compte Shopify créé (essai 3 jours, puis 1€/mois × 3 mois)
- [ ] Domaine connecté à Shopify
- [ ] Thème installé et personnalisé (Dawn recommandé)
- [ ] Couleurs et fonts de marque appliquées
- [ ] Logo uploadé (header + favicon)
- [ ] Devise configurée (EUR)
- [ ] TVA configurée (20% France)

### Paiements
- [ ] Shopify Payments activé
- [ ] PayPal connecté
- [ ] Test transaction effectué (puis remboursé)
- [ ] Apple Pay / Google Pay activés

### Produits
- [ ] Fiche(s) produit créée(s) avec toutes les variantes
- [ ] 6-8 photos produit uploadées (studio + lifestyle)
- [ ] Titre produit optimisé SEO
- [ ] Description complète avec bénéfices
- [ ] Prix et prix barré configurés
- [ ] Stock saisi

### Pages Essentielles
- [ ] Page d'accueil avec hero + bestsellers + bénéfices
- [ ] Page À Propos (histoire de la marque)
- [ ] Page Contact (email + formulaire)
- [ ] CGV (Conditions Générales de Vente)
- [ ] Politique de confidentialité (RGPD)
- [ ] Politique de retours et remboursements
- [ ] Mentions légales
- [ ] FAQ (10 questions minimum)

### Livraison
- [ ] Zones de livraison configurées
- [ ] Tarifs de livraison définis
- [ ] Livraison gratuite dès [X]€ configurée
- [ ] Délais affichés clairement sur les pages

---

## Phase 3 — Marketing (Semaine 3-4)

### Tracking
- [ ] Google Analytics 4 installé et configuré
- [ ] Meta Pixel installé (via Shopify App)
- [ ] Événements Pixel vérifiés (ViewContent, AddToCart, Purchase)
- [ ] Google Search Console vérifié
- [ ] Sitemap soumis à Google

### Email Marketing
- [ ] Compte Klaviyo créé et connecté à Shopify
- [ ] Pop-up inscription newsletter avec offre (10% code)
- [ ] Flow Welcome Series configuré (3 emails)
- [ ] Flow Abandoned Cart configuré (3 emails)
- [ ] Flow Post-Purchase configuré (3 emails)

### Apps Shopify
- [ ] Judge.me installé (avis clients)
- [ ] Vitals installé (reviews + upsell + trust badges)
- [ ] ReConvert installé (thank you page)
- [ ] Tidio installé (chat)

### Contenu Initial
- [ ] 5-10 avis clients importés ou créés (vraies expériences)
- [ ] Photos et vidéos produit prêtes
- [ ] 3-5 créatifs publicitaires prêts (agent-static-ads)
- [ ] Copy pub rédigé (agent-copywriting)

---

## Phase 4 — Lancement Pub (Semaine 4)

### Meta Ads
- [ ] Compte Meta Business Manager créé
- [ ] Page Facebook Business créée
- [ ] Compte publicitaire vérifié
- [ ] Méthode de paiement ajoutée
- [ ] Meta Pixel vérifié dans Ads Manager
- [ ] Première campagne test créée (20-50€/jour)
- [ ] 3-5 créatifs testés simultanément

### TikTok Ads (optionnel départ)
- [ ] Compte TikTok Ads Manager créé
- [ ] TikTok Pixel installé
- [ ] Première campagne test créée

---

## Phase 5 — Vérifications Go-Live

### Tests Techniques
- [ ] Commande test effectuée (vrai paiement + remboursement)
- [ ] Email de confirmation reçu et correct
- [ ] Email d'expédition configuré
- [ ] Page mobile vérifiée sur iPhone ET Android
- [ ] Tous les liens fonctionnels (navigation, CTA, footer)
- [ ] Vitesse de chargement testée (PageSpeed > 60 mobile)
- [ ] SSL actif (cadenas visible dans l'URL)

### Légal
- [ ] CGV accessibles depuis le footer
- [ ] Politique de confidentialité accessible
- [ ] Politique de retours visible sur page produit
- [ ] Mentions légales complètes (SIRET, adresse, dirigeant)
- [ ] Bandeau cookies RGPD actif

### Dernier Check
- [ ] L'offre est claire (prix, délai, garantie)
- [ ] Les photos produit sont de qualité
- [ ] Le checkout est simple (max 3 étapes)
- [ ] Le service client est joignable (email visible)

---

## Après la Première Vente

- [ ] Commande traitée et expédiée dans les délais
- [ ] Email de suivi envoyé au client
- [ ] Flow post-purchase déclenché
- [ ] Analytics vérifié (source de la vente)
- [ ] Optimiser ce qui a conduit à cette première vente

---
