## 3. FORMULES CLÉS

```
ROAS = CA généré / Budget Ads
CAC = Budget Ads / Nombre de clients
LTV = AOV × Fréquence d'achat × Durée de vie client
MER (Marketing Efficiency Ratio) = CA total / Budget Ads total
Marge nette = CA - (Coût produit + Livraison + Ads + Apps)
Break-even ROAS = Prix vente / (Prix vente - Coût total hors ads)
```

**Break-even ROAS VELIRA :**
- Prix vente : €44.99
- Coût total hors ads : €13.00 (produit + livraison + apps)
- Break-even = 44.99 / (44.99 - 13.00) = **1.41x**
- ROAS minimum pour profiter : >1.41x

## 4. DIAGNOSTIC ENTONNOIR

### Si peu de visites → Problème acquisition
- Augmenter budget Meta
- Vérifier CTR (< 1% = changer créatifs)
- Tester nouveaux hooks

### Si visites OK mais pas de conversion → Problème page produit
- Heatmap Clarity (scroll depth)
- A/B test titre produit
- Vérifier temps de chargement (< 3s)
- Ajouter social proof (avis)

### Si conversions OK mais ROAS mauvais → Problème marge/CAC
- Revoir le ciblage (broad vs intérêts)
- Analyser les audiences qui convertissent
- Augmenter AOV (bundle, upsell)

### Si ROAS OK mais pas de croissance → Problème scaling
- Audience fatigue → nouvelles audiences
- Créatifs épuisés → nouvelles créas
- Expansion DACH (AT/CH)
